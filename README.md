# موقع مدارس دلتا — Delta Schools Website

موقع ثابت (HTML + CSS + JavaScript) ثنائي اللغة، العربية افتراضيًا مع دعم كامل للإنجليزية. لا يحتاج إلى npm أو أي مكتبات.

## التشغيل
1. فك الضغط وافتح المجلد في VS Code.
2. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
3. للنشر: ارفع المجلد كما هو على أي استضافة ثابتة (Netlify، Vercel، GitHub Pages، أو خادم المدرسة).

## هيكل المشروع
```
index.html          الرئيسية: مستكشف المسارات، لماذا دلتا، الاعتمادات، الحرم، خطوات القبول
about.html          القصة، الرؤية والرسالة والفلسفة، القيم، فريق القيادة
programs.html       المسارات الأربعة بالتفصيل + جدول مقارنة + شريط تنقل ثابت
campus.html         المرافق، معرض صور بفلاتر وعارض صور، الخريطة
achievements.html   الاعتمادات، معايير ISO، رعاية الموهبة
admissions.html     خطوات القبول، نموذج استفسار من 3 خطوات، الخدمات، أسئلة شائعة مع بحث
contact.html        وسائل التواصل، نموذج رسائل حسب الموضوع، الخريطة
404.html            صفحة الخطأ
css/style.css       نظام التصميم كاملًا (الألوان والخطوط في :root أعلى الملف)
js/main.js          كل التفاعلات
assets/favicon.svg  أيقونة الموقع
sitemap.xml, robots.txt, site.webmanifest   ملفات SEO
```

## تعديل النصوص
النص العربي مكتوب داخل العنصر مباشرة، والإنجليزي في الخاصية `data-en`:
```html
<h2 data-en="Our vision">رؤيتنا</h2>
```
- للخصائص: `data-ph-en` (placeholder)، `data-aria-en` (aria-label)، `data-alt-en` (alt)، `data-title-en` (title).
- العنصر الذي يحمل `data-en` يجب أن يحتوي نصًا فقط (بدون وسوم داخلية).
- القائمة والفوتر مكرران في كل صفحة؛ عند تعديلهما عدّلهما في جميع الصفحات.

## روابط ذكية
- `admissions.html?track=International#enquiry` يفتح نموذج القبول والمسار مختار مسبقًا (القيم: International, National, Egyptian, Special+Education).
- `contact.html?topic=visit#form` يختار موضوع الرسالة مسبقًا (admissions, visit, parent-relations, platform, general).

## النماذج
النماذج تتحقق من البيانات (برسائل خطأ بالعربية والإنجليزية)، ثم تفتح تطبيق البريد برسالة جاهزة إلى `hello@delta.edu.sa`، مع زر لنسخ البيانات. نموذج القبول يحفظ المسودة مؤقتًا في الجلسة حتى لا تضيع عند التنقل.
للإرسال المباشر بدون تطبيق البريد: اربط النماذج بخدمة نماذج أو Backend معتمد من المدرسة (مثل Formspree أو خادم المدرسة) من الدالة `finish()` في `js/main.js`.

## الصور
الصور الرسمية تُحمَّل من خوادم موقع المدرسة الحالي (Wix) بدقة أعلى من النسخة السابقة، وتحتاج اتصالًا بالإنترنت. إذا تعذّر تحميل صورة يظهر بديل أنيق تلقائيًا. يُفضّل قبل النشر تنزيل الصور إلى `assets/images` وتحديث الروابط.

## قبل النشر الرسمي — يحتاج تأكيدًا من المدرسة
- رقم واتساب في زر التواصل السريع (حاليًا 0562210140) — تأكد أنه مفعّل على واتساب.
- أسماء وصور فريق القيادة في `about.html` (مساحات محجوزة حاليًا).
- مواعيد ومستندات القبول للعام الدراسي، وخيارات «العام الدراسي» في النموذج.
- رابط منصة دلتا التعليمية الفعلي (البطاقة حاليًا تحيل إلى صفحة التواصل).
- عنوان الموقع النهائي: غيّر `https://delta.edu.sa` في `<link rel="canonical">` و`sitemap.xml` إن اختلف.
